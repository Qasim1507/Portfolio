Simulation: SUMO Microscopic Engine
Abstract

The conventional traffic signal control system, which is based on centralized, fixed-time, or occupancy-driven systems, does not react to traffic conditions quickly because of a long response time and low adaptability. This research addresses dynamic traffic management by developing an adaptive edge-based traffic management system. The system leverages intelligent hybrid learning models combining reinforcement learning (RL) with rule-based decision-making to optimize traffic signal control in real-time. Using edge computing, the proposed system processes traffic data locally at intersections, enabling decentralized control and significantly reducing response time. A neural-network-based Q-learning agent dynamically adjusts signal phases based on real-time traffic conditions, while a rule-based layer enforces safety constraints such as minimum green times (5s) and pedestrian crossing safety. Evaluated on SUMO across 50 epochs and 500 simulation steps, the proposed model cuts maximum waiting time to 1602.0s (a 14.65% reduction vs. occupancy systems and 9.84% vs. fixed-time baselines) with an edge inference latency of 1.8 ms on CPU.

I. Contributions

  • Edge-Computing Real-Time Architecture: Decentralized signal management that runs locally at intersection nodes, achieving 1.8 ms per decision cycle without cloud round-trip delay.
  • Hybrid RL + Safety Rule Layer: Combines policy exploration via Q-learning with strict rule-based boundaries (minimum green durations, safe yellow clearance, pedestrian prioritization).
  • Extensive SUMO Microscopic Benchmarking: Multi-intersection simulation under randomized demand profiles comparing against calibrated fixed-timing and sensor occupancy baselines.

IV. Conclusion & Edge Feasibility

The Q-learning agent demonstrates O(n) computational complexity where n is the number of monitored lanes. Running entirely within an Intel Core i7 / ARM edge envelope, the decentralized structure scales horizontally without imposing computational burdens on central infrastructure.
