// MODULE 01 · PROBLEM STATEMENT

Surgical Visibility Obstruction by Electrosurgical Smoke

In minimally invasive surgeries (MIS) such as laparoscopy and endoscopy, electrosurgical instruments generate dense surgical smoke. This smoke severely obscures the operative field of view, prolongs procedure duration, and escalates risks of surgical error.

Traditional physical evacuators (fume hoods, vacuum exhaust) suffer from latency and inadequate clearing in confined intra-abdominal cavities, demanding real-time computerized smoke segmentation.

// MODULE 02 · PROPOSED SYSTEM ARCHITECTURE

Hybrid CNN + HSV Saturation Peak Analyzer (SPA)

The proposed framework orchestrates two complementary mechanisms to achieve optimal trade-offs between processing speed and classification acuity:

1. HSV Thresholding & SPA

Isolates smoke regions via color and saturation histogram profiling, yielding ultra-fast initial detection in real time.

2. Custom Pixel-Based CNN

A 3-convolutional layer architecture extracting fine-grained spatial reflectance features from local (N×2)*(N×2) pixel neighborhoods, terminating in a 4-layer fully connected decision network.

Ensemble Combination Strategy

A dynamically weighted average prioritizing CNN decisions during smoke-heavy frames and HSV color parsing during clear tissue viewframes.

// MODULE 03 · PRE-PROCESSING PIPELINE

Artifact Removal & Spatial Normalization

  • Black Border Removal: Eliminates circular endoscope camera masks that introduce false edge detections.
  • Lanczos Resizing: Standardizes input frames to uniform dimensions for continuous video sequence analysis.
  • Adaptive Gaussian Smoothing: Filters out specularity and high-frequency surgical tool glares while preserving subtle smoke boundary gradients.
